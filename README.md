# GO-project

Небольшой backend-сервис на Go.  
Тема проекта — мини-Avito: пользователь может зарегистрироваться, войти, создать объявление и посмотреть свои объявления.

Проект делался по лабораторным работам. В итоге в нём есть:

- HTTP-сервер на Go
- PostgreSQL
- регистрация и авторизация
- JWT
- объявления
- middleware для проверки токена
- RabbitMQ и отдельный сервис обработки
- Prometheus и Grafana
- запуск через Docker Compose

## Запуск

Запуск всего проекта:

```bash
docker compose up --build
